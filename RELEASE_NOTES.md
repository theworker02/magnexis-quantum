# Magnexis Quantum v1.0.0

## Initial public information site

This release establishes Magnexis Quantum as a lightweight GitHub Pages information site for an independent engineering research program.

### Included

- A responsive static landing page with program overview, research focus, partnership expectations, and access-request guidance.
- GitHub Issues as the preferred manufacturer-material access route, with GitHub Discussions as the alternative for general questions.
- A structured manufacturer access-request Issue form.
- Automatic Issue and Discussion links for standard GitHub Pages project URLs, plus a documented setting for custom domains.
- No private plans, controlled drawings, manufacturing artifacts, account system, backend service, or protected document delivery.

### Publishing

Enable GitHub Pages from the `main` branch and repository root. Enable Issues and Discussions before sharing the site publicly.

### Partner boundary

An access request is an invitation to explore an appropriate partnership. It does not authorize manufacturing or operation. Each responsible partner must complete and own the detailed engineering, production, safety, compliance, and qualification work for its scope.
